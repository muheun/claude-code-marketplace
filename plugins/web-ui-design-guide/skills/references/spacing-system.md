# 간격 시스템 (Spacing System)

## 8px 그리드 시스템 (8px Grid System)

모든 margin, padding, gap은 **8의 배수**를 사용하여 시각적 일관성 확보.

## 간격 스케일 (Spacing Scale)

| 값 (px) | 사용 용도 |
|---------|-----------|
| `4px`   | 아이콘과 텍스트 사이, 매우 좁은 간격 (예외적) |
| `8px`   | 인접한 요소 간 최소 간격, 버튼 내 아이콘-텍스트 |
| `12px`  | 버튼 padding (세로) |
| `16px`  | 버튼 padding (가로), 카드 내부 기본 padding, 단락 간격 |
| `24px`  | 섹션 내부 여백, 폼 필드 간격 |
| `32px`  | 카드 간격, 섹션 간 구분 |
| `48px`  | 큰 섹션 간 여백 |
| `64px`  | 페이지 레벨 여백, 헤더/푸터 여백 |

## 컴포넌트별 간격 가이드

### 버튼 (Button)
```
Padding: 12px (상하) × 16px (좌우) - 작은 버튼
Padding: 12px (상하) × 24px (좌우) - 중간 버튼
Padding: 16px (상하) × 32px (좌우) - 큰 버튼
버튼 간격: 8px (인접), 16px (그룹 간)
```

### 카드 (Card)
```
내부 Padding: 16px (작은 카드) ~ 24px (중간 카드) ~ 32px (큰 카드)
카드 간격: 16px (밀집) ~ 24px (표준) ~ 32px (여유)
카드 내 요소 간격: 12px (제목-내용), 8px (관련 텍스트)
```

### 폼 (Form)
```
Label-Input 간격: 8px
Input 내부 Padding: 12px (상하) × 16px (좌우)
Input 필드 간격: 16px (기본) ~ 24px (그룹 구분)
폼 그룹 간격: 32px
제출 버튼 상단 여백: 24px
```

### 리스트/테이블 (List/Table)
```
리스트 아이템 간격: 8px (밀집) ~ 12px (표준) ~ 16px (여유)
리스트 아이템 내부 Padding: 12px (상하) × 16px (좌우)
테이블 셀 Padding: 12px (상하) × 16px (좌우)
```

### 페이지 레이아웃 (Page Layout)
```
컨테이너 좌우 Padding: 16px (모바일) ~ 24px (태블릿) ~ 32px (데스크톱)
헤더 높이: 64px
섹션 간 여백: 48px (작은 섹션) ~ 64px (큰 섹션)
```

## 반응형 간격 (Responsive Spacing)

작은 화면에서는 간격 축소:

```
모바일: 기본 간격의 75-100%
태블릿: 기본 간격의 100%
데스크톱: 기본 간격의 100-125%
```

예시:
```css
/* 모바일 */
gap: 12px;  /* 8px 그리드의 1.5배 */

/* 태블릿 이상 */
@media (min-width: 768px) {
  gap: 16px;
}

/* 데스크톱 */
@media (min-width: 1024px) {
  gap: 24px;
}
```

## 금지 사항 (Avoid)

❌ 임의의 값: `13px`, `27px`, `35px` 등
❌ 일관성 없는 간격: 같은 컴포넌트인데 페이지마다 다른 padding
❌ 과도한 밀집: 모든 요소가 붙어있어 답답함
❌ 과도한 여백: 불필요하게 넓은 공간으로 산만함

## 올바른 사용 예시

✅ **카드 레이아웃**:
```
카드 padding: 24px
카드 간 gap: 24px
카드 내 제목-내용 간격: 12px
```

✅ **폼 레이아웃**:
```
Label-Input: 8px
Input 필드 간: 16px
섹션 구분: 32px
```
