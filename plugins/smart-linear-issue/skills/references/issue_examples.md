**제목**: 🐛 로그인 토큰 만료 시 자동 갱신 실패

**내용**:
```markdown
## 문제 상황
인증 토큰이 만료된 후 API 호출 시 자동 갱신이 되지 않고 로그아웃됨

## 재현 방법
1. 로그인 후 30분 대기
2. 페이지 새로고침 없이 API 호출
3. 강제 로그아웃 발생

## 기대 동작
토큰 만료 시 리프레시 토큰으로 자동 갱신 후 원래 요청 재시도

## 영향 범위
모든 인증된 사용자
```

## 변환 예시

### 예시 1: 버그

**원본 (나쁜 예)**:
```
UserRepository.findById()에서 null 반환 버그

findById() 메서드가 Optional 대신 null 반환함
UserService.getUser() 호출 시 NullPointerException 발생
```

**변환 (좋은 예)**:
```
🐛 사용자 조회 시 존재하지 않는 ID 처리 오류

## 문제 상황
존재하지 않는 사용자 ID로 조회 시 서버 오류 발생

## 재현 방법
1. 삭제된 사용자 ID로 프로필 페이지 접근
2. 500 에러 발생

## 기대 동작
"사용자를 찾을 수 없습니다" 메시지 표시
```
