# SpecKit Plugin for Claude Code

GitHub SpecKit integration for Specification-Driven Development - define WHAT and HOW before coding.

## Commands

- `/speckit.init` - speckit 프로젝트 초기화 및 CLI 설치 확인

## Installation

Add this marketplace to Claude Code and install the plugin.

## Requirements

- Git
- uv (Python package manager)
- specify CLI
